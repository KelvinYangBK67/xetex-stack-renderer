# XSR 1.3 — natural Khitan spacing and shared vertical midline

XSR 1.3 changes only Khitan line-level arrangement. Type A/Type B slot
geometry, the optional U+16FE4 filler, atomic cluster boundaries and
original-source `/ActualText` extraction remain intact.

- U+0020 SPACE now produces ordinary TeX interword glue using the surrounding
  text font, including `\spaceskip`, stretch/shrink and normal wrapping.
  The Khitan font is selected only when drawing signs, not for the outer text run.
  U+200B still provides a zero-width break opportunity.
- A cluster's measured box is shifted vertically so its geometric midpoint
  is at the host font's 0.5em center, regardless of row count. Original glyph
  slot geometry remains untouched; tall clusters now occupy height and depth.
- Existing `\xsrKhitanClusterGap{0.2}` and other numeric overrides continue to
  request fixed em gaps; `normal` restores ordinary host-font spacing.
- The Khitan backend/cache identity is `native-fixed-stack-1.3`, rejecting
  stale responses prepared with the previous spacing behavior.

The regression tests cover Python gap normalization and discovery, TeX box
midlines, normal and fixed `\spaceskip` behavior, Unicode extraction, and
the existing Egyptian, Khitan and generic glyph integrations.

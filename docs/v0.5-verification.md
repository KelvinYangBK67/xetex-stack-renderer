## Scope and implementation findings

Geometry continues to come from the selected font. Hieropy provides structure only;
its alternate glyph recipes and layout methods are not used. Enclosures and damage
are vector paths. Insertion uses bounded occupancy search, not font-specific slots.
The generic core gained typed errors, response validation and an invocation sentinel
because a failed external command could otherwise leave a previous valid response.
The detector gained contextual suffix registration to retain rotation selectors.

Visual verification caught PGF's internal font/dimension context changes during
development. Drawing now explicitly selects the measured font and captures the em
size before entering PGF. The synthetic bearing/descender raster integration test
and embedded-font checks verify these fixes.

This release does not implement continuous lost-sign shading, damaged/ornate
unsupported enclosure caps, RTL, arbitrary TeX expansion or font-name resolution.
Static CFF support is less extensively tested than TrueType. Automatic insertion
may reject unusual/crowded outlines rather than place a colliding child. See the
README support matrix and path/preprocess boundaries for the precise public model.

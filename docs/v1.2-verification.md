## Implemented behavior

The Khitan TeX backend invokes `\mode_leave_vertical:` before emitting
the first atomic `/ActualText` cluster box from
`\xsrKhitanUseFont`. The first cluster therefore joins the host paragraph,
including centered and aligned text and table-cell content. Previously,
the first box could be placed as a separate vertical-list item, leaving only
later clusters under the intended paragraph alignment.

This changes paragraph entry, not the Khitan cluster parser, Type A/Type B
structure, Unicode input or mapping, font metrics, slot geometry, or
public TeX commands. XSR 1.1 `/ActualText` semantics are retained.

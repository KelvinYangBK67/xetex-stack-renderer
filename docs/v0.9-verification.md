## Architecture audit

A. Font-backed glyph measurement/rendering remains in `font_metrics` and the
Egyptian/Khitan packages. Parsers and shaping rules were not rewritten. A thin
`FallbackFont` adapter catches only missing visible glyphs, supplies nominal
metrics/outlines, and records missing codepoints. Script serializers emit generic
geometry at their existing placements. Low-level font lookup remains strict.

B. `vector.py` owns immutable glyph/path/command geometry and affine transforms,
a restricted SVG importer, synthetic hollow boxes, and numeric-only PGF
serialization. Coordinates are normalized into em units before TeX serialization;
quadratics use exact cubic conversion, bounds use Bezier extrema, and strokes
retain transformed canvas geometry. `xsr-vector.sty` places atomic boxes with
explicit advance, height, depth and baseline. Script-specific placements remain
in their own TeX backends.

C. `providers.py` owns optional argv-based process invocation, configuration,
result SVG caching, metadata and an `obtain_many` extension point. The KAGE
commands are aliases/style restrictions over generic provider commands. There
is no KAGE import, implementation, component expansion, data loader or IDS logic.

The existing XSR2 renderer/request/cache protocol remains intact. A generic
`prepare_request` hook validates external inputs before response-cache lookup.
Provider SVG is interchange only, not the final internal representation.

## Public interfaces and restrictions

- Direct SVG: `\xsrVectorGlyph{literal/path.svg}`.
- Generic provider: `\xsrVectorProvider{provider.json}`,
  `\xsrVectorStyle{style}`, `\xsrProviderGlyph{identifier}`.
- KAGE convenience: `\xsrKageProvider{provider.json}`,
  `\xsrKageStyle{serif|sans}`, `\xsrKageGlyph{identifier}`; default serif.
- Provider protocol: `--glyph IDENTIFIER --style STYLE --output ABSOLUTE_PATH`.
  Optional nonempty options object adds one `--options-json JSON` argument.
- JSON configuration: executable, structured prefix_args, optional options,
  metadata and timeout. No command-string parsing, `shell=True`, implicit engine
  imports or shell wrappers. Invocation is `subprocess.run(argv, shell=False)`.
- SVG: UTF-8 `svg/g/path`; numeric/px container dimensions and viewBox;
  `M/m L/l H/h V/v Q/q C/c Z/z`; translate/rotate/scale/matrix and nested groups;
  inherited black/none fill/stroke and numeric stroke width. Default nonzero
  winding, butt cap, miter join/limit 4. Unknown semantics fail explicitly.
- No entities/DTD, scripts, CSS, references, URLs, images, text, filters,
  gradients, masks, clipping, animation or general SVG support. Limits: 2 MB,
  64 nesting levels, finite bounded numbers. No raster or PDF intermediate.
- Design-space height maps to one em and preserves aspect ratio; 200 x 200
  maps to a 1em square, depth zero. Ink bounds never set scale. ViewBox defines
  the design space independently of SVG physical viewport dimensions.

## Caching and preprocessing

Direct input identity includes normalized absolute path, source content MD5
(the TeX bridge), authoritative SHA-256, importer version and options. Provider
identity includes configuration/argv, identifier, style, options/metadata,
resulting SVG SHA-256 and importer version. Producer metadata is stored next to
cached SVG. Change the configured revision or clear the provider cache after
changing an external engine/dataset; XSR cannot discover unreported revisions.

Preprocessing follows literal includes and brace scopes for provider/style and
missing-policy selections. Unique glyph requests are generated once. External
identifiers/paths are excluded from font-backed script discovery. Frozen
responses compile with `-no-shell-escape` without starting a provider; the
SVG/config files remain present for content checks. Shell mode memoizes repeated
requests within a document and reuses successful producer results across builds.
Source SVG modifications invalidate responses. Malformed SVG always reaches a
typed diagnostic, including corrupted cached provider interchange.

## Tofu policy

Default `box`; strict `error` via Python `missing_glyph_policy` or scoped TeX
`\xsrMissingGlyphPolicy`. Hollow compound vector paths occupy a nominal 1em cell
in each script's normalized font units, independent of `.notdef`. KSS U+18CFF
in Noto v1.000 now occupies its normal slot with a typed warning; no XeTeX
missing-character warning is emitted. Type A/B structure remains intact.
Egyptian missing signs retain normal H/V packing and scaling. Script controls,
separators and variation selectors never become tofu. Empty outlines retain
the separate existing `XSR-GLYPH-EMPTY` diagnostic.

Provider fallback distinguishes UNAVAILABLE, MISSING, FAILED and SVG error
codes. Invalid configuration and malformed direct SVG remain fatal. Cached
TeX fallback responses also emit typed warnings.
